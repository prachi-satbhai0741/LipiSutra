LipiSutra is a multimodal platform that reads, reconstructs and preserves historical Indian manuscripts. The home page lets a user upload an artifact image and receive a transcript, a modern translation and a summary.

Scripts Recognised by the System

  • Modi
  • Devanagari
  • Brahmi
  • Sharada

Steps to Decode a Manuscript

  1. Open the LipiSutra web application in the browser.
  2. Drag and drop a high-resolution image of the document.
  3. Click the "Decode & Analyze Artifact" button.
  4. Read the transcript, translation and summary tabs.
  5. Listen to the narrated output using text-to-speech.

Platform Roles

  • Public / Student
    1. Upload an artifact
    2. Read the AI output
  • Historian
    1. Review a pending document
    2. Correct and verify the transcript
  • Museum Admin
